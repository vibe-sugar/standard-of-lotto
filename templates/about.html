💡 서비스 소개

로또의 정석은 어떻게 만들어졌을까요?

서비스 개요

로또의 정석은 동행복권 공식 데이터를 기반으로 역대 로또 6/45 당첨 번호를 분석하여, 통계적으로 의미 있는 번호 추천을 제공하는 서비스입니다.

단순한 무작위 추천을 넘어, 역대 당첨 번호의 합산 구간 분포와 번호별 출현 빈도를 시각화하고, 사용자가 원하는 조건에 맞는 번호를 추천받을 수 있습니다.

모든 추천 번호는 DB에 저장되며, 실제 당첨이 발생하면 메인 화면에 즉시 공개하여 완전한 투명성을 보장합니다.

🗓️ 2002년~현재 데이터 커버리지
🔄 매주 자동 업데이트 배치 프로그램 운영
🔓 100% 투명 공개 추천 번호 당첨 이력

주요 기능

01

완전 무작위 번호 추천

1~45 범위의 숫자 중 편향 없이 완전 무작위로 6개 번호를 선택합니다. 한 번에 최대 5세트까지 동시에 생성할 수 있습니다.

02

합산 구간 기반 번호 추천

6개 번호의 합계가 특정 구간(예: 121~130)에 들어오는 번호 조합을 추천합니다. 역대 데이터 분석 결과 당첨 번호의 합산은 특정 구간에 집중되는 경향이 있습니다.

03

통계 시각화

번호별 출현 빈도, 합산 구간 분포 등 다양한 통계 데이터를 차트와 히트맵으로 시각화합니다.

04

투명한 당첨 이력 공개

이 사이트에서 생성된 모든 추천 번호는 DB에 저장됩니다. 실제 당첨(1~3등)이 발생하면 메인 화면에 즉시 공개합니다.

로또 번호 색상 안내

로또 6/45의 공식 번호 색상 체계입니다.

5 1~10번 — 노란색
15 11~20번 — 파란색
25 21~30번 — 빨간색
35 31~40번 — 회색
43 41~45번 — 초록색

기술 스택

🐍 Python 3.12 백엔드 / 배치
🌶️ Flask 웹 프레임워크
🗄️ MySQL 데이터베이스
📊 Chart.js 데이터 시각화

배치 프로그램 실행 방법

수동 실행

cd /path/to/webapp
python batch/fetch_lotto.py

자동 실행 (Linux cron)

# 매주 일요일 오전 9시에 자동 실행
0 9 * * 0 cd /path/to/webapp && python batch/fetch_lotto.py

자동 실행 (Windows 작업 스케줄러)

cd C:\path\to\webapp
python batch\fetch_lotto.py

⚠️ 주의사항

  • 본 서비스는 로또 당첨을 보장하지 않습니다.
  • 모든 번호 추천은 통계적 분석에 기반하며, 실제 당첨 결과와 무관합니다.
  • 로또는 사행행위입니다. 과도한 구매를 삼가시기 바랍니다.
  • 미성년자의 로또 구매는 법적으로 금지되어 있습니다.
  • 당첨 데이터는 동행복권 공식 API를 통해 수집됩니다.
